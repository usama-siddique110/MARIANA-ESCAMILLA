Welcome to the official repository for the **MARIANA ESCAMILLA LLC** website. Mariana Escamilla LLC is a premier digital technology and design firm that merges visionary design, relentless engineering, and adaptive AI to launch digital products that dominate their markets.

This website is styled with an executive **Luxe Amethyst & Sunset Rose Aurora** dark theme.

## ✨ Features

- **Orbital Tech Cursor**: A custom-crafted magnetic cursor featuring three rotating orbital particles that track mouse movements and dynamically expand on interactive triggers.
- **Luxe Aurora Palette**: A deep midnight obsidian canvas enriched with Royal Amethyst (`#8B5CF6`), Radiant Sunset Rose (`#EC4899`), and Luminous Aqua (`#06B6D4`) glowing highlights.
- **Pulsing Quantum Orbits**: Animated concentric orbital loops with a pulsing glowing core in the hero showcase.
- **Advanced Interactivity**:
  - **3D Tactile Tilt**: Service and technology cards dynamically tilt in 3D perspective based on pointer coordinate offsets.
  - **Magnetic Buttons**: Call-to-action buttons smoothly pull toward the user's cursor.
- **Premium Typography**: Built with Google Fonts `Syncopate` and `Outfit` for a luxury, modern executive aesthetic.
- **Dynamic Nebula Atmosphere**: Layered floating ambient nebulas rendered with CSS radial gradient meshes.
- **Responsive Layout**: Designed for seamless display across 4K displays, laptops, tablets, and smartphones.

## 🛠️ Technology Stack

This project is built using modern **Vanilla Web Technologies** for peak performance and instantaneous loading speed:

- **HTML5**: Semantic, accessible markup with SEO metadata.
- **CSS3**: Custom design system, CSS Variables, glassmorphic backdrop filters, grid/flexbox layouts, and hardware-accelerated animations.
- **JavaScript (ES6)**: Vanilla JS for scroll reveals, 3D card tilt physics, cursor kinematics, and mobile drawer transitions.
